架构一眼看穿：T3 Connect 不是 Tailscale，自建线路完全不用登谷歌账号 代码直连模型，永不经 T3

官方 T3 Connect 本质是「Clerk 身份认证（谷歌/GitHub 登录）+ Relay 撮合发门票 + Cloudflare Tunnel 隧道」，不是虚拟局域网 VPN。只有走官方云穿透才需要登 Clerk 账号；你走局域网、Tailscale 或自己 VPS，全靠本地生成一次性配对码交换加密凭证（DPoP）。

重要区分：AI 模型账号（如 Antigravity 的谷歌号 / Claude / Codex）永远只留在干活主机本地，与 T3 登录是两码事
用自己的服务器 / 内网怎么搞？3 条路线切换对比 推荐选 A 或 B

像 Tailscale 吗？这就是原版 Tailscale 本尊。Mac 和一加 15 装好 Tailscale 拉进同一个私有虚拟局域网后，T3 Code 会自动识别 Tailnet IP 和 MagicDNS HTTPS 域名（https://机器名.tailnet.ts.net），完全免登谷歌/Clerk 账号。作者 Theo 自己出门也经常切 Tailscale 做备用线路。

  • 多路线自动热切换：把「家里 LAN → Tailscale → T3 Connect」都保存成同一台机器的多条 Route，在家秒走千兆内网，出门自动滑到 Tailscale，极端情况才走云穿透。
  • 开启方式：桌面端在 Settings → Sharing & access 打开 Tailscale HTTPS；或直接跑终端命令生成扫码二维码。
t3 serve --tailscale-serve && t3 pair --tailscale

福总你手头本来就有 VPS，这条路非常顺手，同样完全免登谷歌账号。注意 app.t3.codes 网页端和外网配对要求 HTTPS（可用 Caddy 一行反代自动签 Let's Encrypt 证书），客户端选「Add Environment」粘贴域名和 t3 pair 配对码即可。

  • 用法 1（VPS 当反代网关）：VPS 通过 WireGuard / FRP / SSH 隧道反代家里 Mac 的 127.0.0.1:3773，公网域名直达家里电脑。
  • 用法 2（直接把干活环境搬上 VPS）：在 VPS 上跑 t3 serve（或桌面端直接 Add Environment → SSH 托管），彻底告别 MacBook 合盖断网；注意模型 CLI（Claude/Codex/Antigravity）需在该 VPS 上登录。
t3 up --lan && t3 pair --ttl 15m

源码 infra/relay 确实开源，但个人自建属于「杀鸡用牛刀」。它不是一个轻量化 Docker，而是整套云原生控制面：

  • 依赖重：必须自备 Cloudflare Workers + PlanetScale 数据库 + 自己申请一套 Clerk OAuth / JWT 模板。
  • 还要自己重编客户端：官方预编译桌面端/手机端把 Relay 域名写死在构建环境变量（T3CODE_RELAY_URL）里，自建 Relay 必须自己编译整套 App 和配 Apple APNs / Google FCM 推送证书。
⚡ 黄金混合姿势（兼顾隐私免费 + 通知体验）

纯走 Tailscale / 自有 VPS 时，不会有 iOS 灵动岛、Android FCM 锁屏推送和访客链接（这两项依赖官方 Relay 转发）。 最优解：你主力 Mac 本身就只有 1 台，继续留着免费的 T3 Connect 收手机进度通知，同时把 LAN + Tailscale 路线加进同一台机器并拖到最前面——日常流量全走你自己的加密内网，既有推送又不花一分钱！

🌏 官方中文主页 t3.codes/zh 安装 / 文档入口

官网页自带简体中文版（/zh），可下全平台安装包（Mac/Win/Linux/iOS/Android）或复制一键 CLI 安装脚本；本地无界面服务器跑 curl -fsSL https://t3.codes/install.sh | sh 即可。

🖥️ 网页控制台 app.t3.codes 支持 Prompt Links

任何能上网的电脑免装客户端直连你的 HTTPS 主机；还支持拼装 Prompt Link（如 app.t3.codes/new?prompt=...&repo=...），分享给别人只预填草稿不自动执行，安全分享修 Bug 模板。

1. 跨机互相派活（Linked Environments）Labs

在 Mac 和 VPS 互连后，在 Mac 聊天框直接说「把这个任务交给我的 VPS」，Agent 自动跨机起线程跑完再回传结果，支持只读旁观。

2. 多机自动负载均衡（Auto Balance）≥2 台可用

手头有 2 台以上主机时，在 Settings → Environments 设偏好权重，新开对话自动挑 CPU 和内存最空闲的机器跑。

3. 共享浏览器 + 手机原生开 localhost超好用

电脑跑起前端服务后，手机能看流式画面并接管点击，长按 localhost 链接还能在手机原生浏览；桌面端支持一键导入 Chrome/Safari Cookie。

4. 内置真机/模拟器直播（Device 面板）移动端调试

把 iOS 模拟器或 Android 模拟器直接嵌在对话右侧（还支持浮窗），边看 Agent 自动点 UI 测 App，边手动点几下。

5. 24h 访客围观链接（Guest Links）Labs

右键线程生成 24 小时一次性分享链接，同事免注册就能看进度和插话提问，每条提问必须经你点 Send 才会发给 Agent。

6. 持久化工作流（Workflows）Labs

在 ~/.t3/workflows/ 用 TypeScript 写多阶段流水线（排查→修复→人工审批→发布），支持定时任务、Webhook 触发和断电续跑。

7. 双 Shift 秒截屏喂图（SnapShot）效率神器

连按两下 Shift 瞬间抓取任意应用窗口截图（可选附带窗口文字），直接塞进当前对话草稿里问 Agent。

8. AI 对话换皮肤 + CPA 额度池面板极客必看

支持导入 VS Code 主题 JSON 和自定义 CSS，甚至直接在对话里让 Agent 调 t3_theme_set 改配色；Usage 页原生支持对接 CLIProxyAPI 聚合看板。
