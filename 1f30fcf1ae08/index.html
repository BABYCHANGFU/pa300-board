# 《海阔天空》Beyond：本次逐首判断

## 材料与边界
已完整阅读本批 README、精选版规则、特色版四条红线、《夜曲》精选版注释与特色版方案、《十年》方案和配置示例。只在本批目录写方案，由指定门控生成新产物，不覆盖旧版本。
本机以简繁歌名检索均未找到谱，故标注：非台湾谱。以下以现有源 MIDI 和当前网格生成的结构图为准，不把自动和弦标签当权威谱。旧档案起点为 1.37 秒，当前网格起点约 3.107 秒，旧档案半小节标签已过时，不照搬。
演唱：Beyond；词曲通常署黄家驹，现有材料未给编曲署名，本次不冒认。没有进行真人演唱试听判断；结论来自源音符、逐小节响度与结构。

## 读歌五问
1. 调、速度、律动：整体 F 大调，约 77 拍，四四拍慢速摇滚抒情。0—48 小节长时间以钢琴为主，49 小节乐队开始进入，50—58 小节稳定鼓贝斯推动；59—62 小节围绕 D 的局部和声不是全曲永久转调。主歌应听到钢琴低音落点后的分解与停顿，不是匀速八分音符跑阶。
2. 前奏在哪里、谁在弹：0—4 小节完整钢琴引子，当前源文件可提取 46 个钢琴音，无人声，无鼓。低音与上方旋律共同构成辨识度；4 小节后半挂留，不另接一遍凑八小节。
3. 真间奏在哪里：30—31 小节是两小节纯钢琴换气，31 小节由小和弦到属挂留，再接 32 小节“今天我”。49—58 小节是十小节纯器乐间奏，不能笼统叫作八小节吉他独奏：失真吉他在49—51小节仅14音，51小节后旋律大量落在弦乐轨，55—58小节尤其明显。49—54与55—58分成前后完整分句分配按键，不丢掉弦乐轨、不用人声轨冒充独奏。84—96 小节还有器乐尾奏，失真吉他含中低音扫弦和高音旋律，97 小节后音频淡出。
4. 主歌、副歌织体：5—19 小节钢琴独唱式陪伴，21—29 小节第一遍副歌仍只有钢琴；32—38 小节第二遍主歌仅36—38有轻鼓。40—48 小节副歌钢琴更饱满，但不能凭歌词假称已有全乐队。60—70 小节钢琴、失真吉他、弦乐、贝斯、直拍鼓共同展开，66 小节响度达到1.00。76—83 小节最终副歌钢琴与弦乐更宽，叮叮镲维持向前，不能再叠一条主唱旋律抢唱。
5. 特别时刻：71 小节首拍吊镲后全乐队骤收，72—74 小节只剩钢琴与弦乐，这是呐喊中的回望；75 小节军鼓重新推回76后的副歌。63、70、75、86、90、94、102为鼓过门候选，门控还会检查后两拍推进。97—103音频淡出，102虽有源MIDI终止滚奏，录音中已几乎听不到；不能把这几小节假称为清晰的录音收尾。

## 情绪路线
寒夜独行 → 抬头坚持 → 放声呐喊 → 忽然回望 → 众声远行。

## 间奏覆盖表
原曲位置 → 按键 → 保留声部 → 接回哪句

- 30—31 → 前奏3 → 完整钢琴换气句 → 32小节“今天我”。特色版改为独立两小节钢琴属挂留引子，仍保留此处的入口逻辑，不截前奏1。
- 49—54 → 前奏2 → 钢琴、49—51失真吉他实录，以及50—53弦乐真实旋律 → 可接间奏后半；现场简用时接主歌，非冒充原录音的直接回唱。
- 55—58 → 过门4 → 原弦乐高线和钢琴，完整四小节推进 → 59小节“仍然自由自我”。特色版用真实弦乐旋律领奏，不写通用上行音阶顶替。
- 84—90 → 尾奏1 → 原器乐尾奏的吉他高线及其和声骨架 → 不接唱，落主和弦结束；这是从长淡出尾奏中选完整落点，并非声称还原全部十三小节。

十小节间奏超过单键八小节上限，必须用前奏2接过门4覆盖；只按前奏2会遗漏后四小节，这是现场操作的已知负担。

## 精选版预案
四级互不重叠：变奏1用5—12钢琴；变奏2用51—58初进乐队；变奏3用60—67失真吉他展开；变奏4用76—83钢琴弦乐更宽的最终副歌。变奏1大小和弦从同一主歌段选材，同一暖中音区，不跨借前奏高音。
前奏1为0—4；前奏2为49—54；前奏3为30—31。过门1、2、3分别取63、75、94。尾奏1取84—90，尾奏2借73小节无鼓钢琴弦乐的主和弦色彩收束，尾奏3取102小节原MIDI最终主和弦滚奏。尾奏2原本有唱词，成品不保留人声；尾奏3录音已淡没，不伪称录音中的响亮末击。
已确认当前精选版编译器将过门1—3固定生成为纯鼓，无法仅靠选段JSON保留同小节贝斯与和声；不越权修改脚本、不暗加音符，这条与“过门不断电”的要求存在真实缺口，必须在说明中明示。

## 特色版预案
不照抄旧海阔天空方案。保持钢琴摇滚身份，主歌用中音钢琴不等距分解与句末空隙；乐队在变奏2出现，变奏3以失真五度托底，变奏4用更宽弦乐而非更密旋律。前奏2和过门4分别提取49—54、55—58真实旋律。过门3用71小节骤收的情绪，但后半军鼓轻推、贝斯和声续住，避免变成无伴奏空洞。三尾奏分别为真尾奏高线接主和弦、独立钢琴柔和下落、乐队短终止。

## 海外曲风版判断
不做。此曲最重要的是漫长钢琴独白到直拍摇滚集体呐喊的结构，现有间奏还存在吉他旋律误分到弦乐的限制；再换拉丁、摩城或合成器会稀释辨识度，不能为凑版本把它改成另一首歌。
